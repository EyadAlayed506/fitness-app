## Found by CI (run #3, 2026-11-16) and fixed

`2 failed, 286 passed`: both smoke tests reported "sign-up is closed" as failing with `HTTP 422`. Cause: the
sign-up request was validated before the closed-sign-up check, and the email validator rejects tester
addresses such as `ali@pilot.local`, so a closed server answered 422 instead of 403. Fix: the closed check is
now a route dependency, which FastAPI runs before validating the body, so a closed server answers 403 to every
sign-up attempt; the smoke check sends a deliberately invalid sign-up and treats 409/422 as "open". New test:
`test_closed_signup_answers_403_before_checking_the_request`.
